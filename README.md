# DLTUI-Viewer
Welcome!

This is a hobby project done during my free time to improve my rust knowledge.

The goal of this project is to provide a DLT-Viewer in TUI, hence the name DLTUI-Viewer.

[DLT-Viewer](https://github.com/COVESA/dlt-viewer) is an open-source GUI application developed by COVESA, mainly used in automotive to read logs and perform diagnostics.

Like many developper, I like to centralize all my work and developpement flow in the terminal. Moreover, as a real developer, I don't need a mouse 😃.

Currently it is a work in progress and not functional, however if you are interested by the project feel free to contribute.
